BlueprintViewer 宿主验证页（纯静态 / UMD）

本页只做两件事：<script src="./dsp-blueprint-editor.umd.js"> + 用类实例 API 控制。 把整个 dist-lib/ 目录搬到任意路径（任意子目录、任意文件名）后用静态服务器打开本页， 都应当全绿——页面里没有任何绝对路径，资产靠 UMD 自动探测脚本同级目录。 注意：必须用 http(s):// 打开，file:// 会被浏览器 CORS 拦住。
