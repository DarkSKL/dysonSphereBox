## 1. 数据口径

**下文间距均为蓝图原始 Area 局部坐标中的中心间距。不是模型边缘净空，不直接等于米，也不是已经验证的任意纬度安全间距。** 这些值用于复现这个样例的局部设计、建立实验候选和校准坐标变换。

- 建筑编号指 `Building.Index`，不是数组下标。
- 原始数据保留 float32；正文一般显示 6 位小数，仅用于阅读。
- 所有建筑引用 Area 0。表中的 X、Y、Z 都来自该 Area 的 `LocalOffset`。
- 同类机器按 Y 升序分行：同一组最大 Y 与首个 Y 的差不超过 `0.002`。组内按 X 排序。
- `ΔX 中位数`：组内相邻机器的 X 差中位数。缺位、塔区和特殊端部会产生更大的空档，因此不能用中位数推断每一台都处于完整周期。
- `ΔY`：两条表内相邻 Y 行的中心均值差。单台补位行单列，不将它与主阵列混为统一行距。
- 朝向只在统计时近似归类为 0°/90°/180°/270°，原始微小偏差仍保存在样本 JSON 中。

配套数据：

- [参考蓝图结构统计.json](参考蓝图结构统计.json)：数量、区域、坐标范围和最小局部距离样例。

### 5.1 分拣器端点不是带节点中心

例如制造台 1198：

| 字段 | 输出臂 4066 | 输入臂 6092 |
| --- | --- | --- |
| ItemID | 2014 | 2013 |
| InputObjIdx → OutputObjIdx | 1198 → 17624 | 9773 → 1198 |
| InputFromSlot / OutputToSlot | 8 / -1 | -1 / 6 |
| LocalOffset | (9.213096, 62.463837, -0.00035705793) | (7.167879, 63.440220, 0.0013824442) |
| LocalOffset2 | (9.282122, 63.490234, -0.0006774925) | (7.4784427, 62.463837, -0.00035705793) |
| FilterID | 0 | 0 |
| Parameters | `[1]` | `[1]` |

其输出带节点 17624 的中心却在 `(10.161760, 63.288956, 0.50000860)`。因此，不能用“分拣器末端坐标必须等于带节点中心”判断连接有效性，也不能只移动带中心而忽略 `InputOffset`、`OutputOffset`、完整槽位、两端姿态和游戏粘贴修正。完整字段见 JSON。

### 5.2 所有机器均为一进一出

扫描全图显式引用发现：**2,113 台生产机器，每台恰好有 1 条输入臂和 1 条输出臂。** 这些直接连接机器的分拣器 `FilterID` 均为 0。

| --- | --- | --- |
| 35，488 台 | 488 / 0 | 97 / 391 |
| 61，195 台 | 195 / 0 | 0 / 195 |
| 106，260 台 | 260 / 0 | 0 / 260 |

这与描述中的混带相呼应：例如配方 107/108 在数据集中有两种原料，但样例仍只有一条机器输入臂。该事实可以解释其局部端口占用较少；尚不能据此认定任意混带启动过程、配比或长期吞吐均已验证。

对全模式超密度功能的影响：必须研究多原料独立输入时增加臂/轨道的可行变体。不能把该样例“一进一出”直接套到所有配方，也不能因当前某个多原料变体尚无解而把产品改成只能使用混带的单独模式。

### 5.3 其他高度数据

- 43 段高速传送带首端 Z 全部约 4.000；43 个高速分拣器首端也约 4.000。
- 喷涂机首端按 Z 四舍五入到两位统计：120 台约 4.00，12 台约 3.00，4 台约 4.75。

## 6. 与当前生成器的数值对照

当前 `geometry.json` 与 `machine_spacing.go` 给出的普通单排初始值：

| 类型 | `space` | 额外安全余量 | 用户附加间距为 0 时的单排中心步长 |
| --- | ---: | ---: | ---: |
| 熔炉 Type 1 | 3 | 0 | 3 |
| 制造台 Type 2 | 4 | 0 | 4 |
| 化工 Type 4 | 7 | 1 | 8 |

当前 `line_spacing` 对应的是产线中上下带组之间的间隔参数，不是两排机器的最终 Y 间距；不能拿它与上面的机器行距直接相减。

例如化工厂在参考图早期行中 ΔX≈6.66212，而普通机器行初始步长为 8；这个对照可以定位候选生成的不同，但**不能直接宣称物理宽度节省 16.7%**：参考图局部坐标和现有排布的球面映射尚未统一。熔炉在高 Y 区域的 ΔX 比 3 大，也不能据此说它不密集，其较小的行距和窄行间运输同样重要。

因此方案中的目标数据应包含“横向节距函数 + 纵向双排周期 + 朝向 + 局部带高度 + 端口拓扑”，而不是只有一个统一间距数字。
