# 能量矩阵1600/min全一级直连修复验收

2026-11-11。复现配置为原版、能量矩阵6002、1600/min、超密度、传送带模式、一级传送带与分拣器、一级生产建筑、研究站一层、赤道环中心、不开喷涂或流速监测。量化计划保持214台炼油厂、107台熔炉和160台研究站，共481台生产设备。

## 原因与修复

大型产线进入原生球面装箱。原料口原先只在高纬检查高度，而且检查包络跨度，未限制在实际frame的局部纬向范围；成品和副产物口又可独立向上下无限找空位。因此出现实际frame之外的端口，随后大量重复搜索直至四分钟超时。

现在原料和交付口共用实际frame范围。先按原有物品、生产行毛能力和净份额规则计算交付组，为每组预留地面两格槽，再在剩余行及合法高层安排原料。创建实体前证明容量；出口继续落地、原料继续从左侧进入，不增加带速或合并不同物料。非原生位置算法保持原有行为。

原生装箱曾只用分流器的十字建造盒，路由却使用完整选择体积。已复现另一分流器的选择体积侵入目标带头约6毫米，导致全部接驳方向失效。装箱现在复用路由的完整分流器净空形状；仅检查跨单元净空，保留同单元真实端口连接，没有缩小模型或扩大端口豁免。

全域A*真正耗尽300000次展开且未取得路径时，原生密铺增加两档有限XY走廊重试。仍使用同一A*、真实障碍、带长、完整后缀、成本和32层上限；累计报告每次调用及展开，所有退出均恢复边界及势场缓存。原搜索已成功时直接保留其结果；局部走廊失败不能作为全域无解证明。另将不变目标后缀提前取出，减少每个展开节点的重复浮点哈希；129组独立对照的路径、目标、展开数及诊断一致。

另一个独立问题是完整结果被慢候选拖失：中间版本已有候选在136秒和182秒通过全部终检并编码，仍因同波其它候选未退出而在240秒整体失败。现在只对原生球面、超密度、直连且至少256台生产设备的请求启用首个可行波次收口：首个完整结果产生后最多等待五秒，使慢候选通过私有上下文退出，同波完整结果仍按原索引顺序择优，再停止后续波次。父请求取消或截止始终失败；没有完整可行结果时继续原搜索。普通模式、小厂及通用Waves不改变。
