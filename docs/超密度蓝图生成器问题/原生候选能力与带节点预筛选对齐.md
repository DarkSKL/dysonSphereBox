# 原生候选能力与带节点预筛选对齐

2026-11-09，基于 `807dfce`。本阶段继续处理937台原等级设备的运输船60/min整厂生成，修复无效候选消耗搜索预算及带节点预筛选过度拒绝的问题。第3至5档运输船整厂目标尚未完成。

## 实现

根球面候选不再运行尚未建立原生单元坐标的塔场路径。该路径不调用 `placePolarUnitFrames`，最终 `preparePolarRootEncoding` 明确拒绝缺少 `polarFrame` 的结果；原先仍可能花费装箱和接线预算。仅根球面阶段排除此类候选，单纬圈路径仍保留塔场候选，实际候选计数和预览计划同步更新。

细化装箱与正式检查共用带节点形状计算：正式检查使用0.23米节点球，并要求缩短胶囊也侵入建造盒才拒绝。原装箱仅凭更大的0.25米节点球拒绝，会误排除部分合法转角。新的细化检查没有放宽正式检查、节点合并、静态盒、塔距、货物采样或分拣器规则。

最终实现完整保留原装箱及其纬向修复序列，仅当其全部失败且未取消时，再细化节点检查。不能直接替换旧策略：A/B试验中，直接替换令赤道运输船由342×61、7塔变成368×60、8塔，总带长也由约50,104米增加到59,722米。这一策略已撤下；最终版本恢复原有结果。

细化胶囊仅使用同一刚性单元内已经存在的真实带邻居。跨单元接线尚未建立时，不推测胶囊方向。未知原型、非几何错误及取消不会被当成细化依据。

## 验证

- 74组公开生成回归通过：矩阵240/min共54组、360/min共2组、480/min共4组、开启检测器的600/min共4组、硫酸120/min共2组、制造台Mk.II 30/min南北极点侧四模式共8组。制造台仍以硅石直接作为原矿输入。
- 运输船60/min完整937台链在赤道中心与第2档北半球中心重新生成并通过复核，保持342×61和784×28。所有设备、配方和产量约束按原请求保留。
- 以上76份均严格解码，核对机器数量、设备等级、机器Yaw正交及Pitch/Tilt为零，并重放带长、静态盒、动态规则、真实静态盒纬界及供电检查。与上一阶段对应结果相比，包络面积均无变化。
- 真实制造台建造盒的四个针对性案例通过：转角和距盒0.24米的位置允许；直线侵入和带端侵入仍拒绝。两种结论均与正式占用检查一致。
- 使用上一提交的完整占用检查作为独立对照，对第3档矩阵及南极边缘制造台执行50组原始/扰动记录检查。新旧正式判定及错误信息完全一致，未通过修改终检取得成功。
- 预览协议3、4在普通单纬圈和根球面各检查一次，均只完成一次正式预览；协议4有明确获选候选。根球面矩阵仅声明7个可用候选，普通单纬圈仍保留10个候选；计划发布时取消不会产生正式结果。
- 已查看第2档运输船完整链、南极侧制造台的原生几何投影及四个节点案例图。图像是离线投影，不是游戏截图。

`go build ./...`、`wails build -s -skipbindings -m -nosyncgomod`与`git diff --check`通过，已更新 `build/bin/DysonSphereBox.exe`；本轮没有前端或绑定接口变更。
