# 球面大厂均衡矩形阶段验收

本阶段在 `b13e079` 的共享原料塔口基础上，为大型超密度塔产线增加独立的均衡矩形候选。第二档北半球中心、运输船60/min的完整937台生产链，由783×26格缩为498×40格；仍使用4座星际塔，实际带长减少约15.8%，包络面积减少约2.2%。没有降低产量、升级设备或外供中间产物。

## 实现

原生装箱原先找到某一纬度的首个合法位置就提交，容易沿经向铺成长条。新候选跨纬度比较单元的经向右边界，保存完整状态后只提交一次。宽纬带采用内部预算的五分之四，窄纬带保留完整预算；各单元与最终实体仍受所选档位的真实边界约束。

紧密排列之后再补电会遇到没有合法电塔位置的问题。新候选先在刚性单元内安排真实电塔，把电塔原型盒和设施间距一起交给装箱器。预排用真实覆盖半径的90%留出球面变换余量，最终仍按真实半径复核覆盖和电网连通，并裁剪冗余电塔。用户关闭供电时不启用预置；局部装配的临时禁用不会覆盖原始选项。

该候选的供电净空使用现有正式规则中的带节点球与缩短胶囊，并保持同批预览中分拣器与非分拣器的互免规则。分拣器仍作为真实耗电消费者检查。没有缩小静态建造盒、放宽设施间距或跳过最终碰撞检查。

同时修复原生包络在零边界的浮点误拒绝：已复现约 `-1.42e-15` 格的运算尾差被当成真实越界。仅消除合法纬向量级内八个float64 ULP的误差；量级上限为500格，真实负坐标仍拒绝，最终建造盒纬界检查保持不变。

新路径通过候选私有上下文隔离，不使用全局试验变量。原有候选保留；先比较实际塔数，同塔数沿用面积、长宽比与真实带长约束。新增候选不会因为形状更短就放过更大的包络。

## 实测结果

| 完整运输船60/min | 上阶段 | 本阶段 |
| --- | ---: | ---: |
| 第二档北半球中心包络 | 783×26 | 498×40 |
| 第二档包络面积 | 20,358格² | 19,920格² |
| 第二档长宽比 | 30.12 | 12.45 |
| 第二档真实带长 | 68,901.359米 | 58,033.292米 |
| 第二档星际塔 | 4 | 4 |
| 赤道中心包络 | 342×61 | 342×61 |
| 赤道中心真实带长 | 50,104.026米 | 50,104.026米 |
| 赤道中心星际塔 | 7 | 7 |

两例均保留490台熔炉2302、267台制造台2303、120台炼油厂2308、60台化工厂2309，共937台。所选带、臂等级和硅石原矿输入保持不变。第二档由公开 `Generate` 入口选中新候选；赤道仍选用更合适的既有候选。

74组公开生成回归全部成功，包络面积和真实带长没有较上一阶段增加：电磁矩阵240/min的27位置×直连/星际模式共54组，480/min四组，第三档北半球南边缘360/min两组，600/min开启监测四组，硫酸120/min两组，以及制造台30/min的南北极点侧×四模式共八组。制造台使用硅石原矿，没有改成石矿制硅。

74份回归及两份完整运输船结果均严格解码并重放球面几何、带距、分拣器、设施间距、真实建造盒纬界和供电检查；设备物品/配方数量逐项对照请求，生产机器保持正交朝向。反例分别拒绝建筑重叠、电力设施过近、真实纬界溢出，以及以更大包络替换原方案。微小舍入尾差、真实负坐标、极大异常坐标、重复预算处理、关闭供电和取消也进行了针对性检查。

同一新候选分别通过预览协议3和4，最终均提交38,647个建筑；协议4完整快照数量与正式结果一致。后端 `go build ./...` 及 `wails build -s -skipbindings -m -nosyncgomod` 通过。未修改公开接口或手改绑定。
