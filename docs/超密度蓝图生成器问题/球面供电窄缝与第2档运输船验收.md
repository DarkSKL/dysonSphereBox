# 球面供电窄缝与第2档运输船验收

2026-11-09，基于`107c13c`继续开发。生产密度规则仍为`dense-v7-spherical-refinery`。

## 修复

球面补偿后的可放置电塔窄缝可能位于任意小数坐标。旧供电器将耗电中心取整到共享半格网，稀缺域继续使用同相位的四分之一格网，因而漏掉真实合法位置。

在保留共享格网的基础上，仅为候选少于8个的球面耗电点增加相对真实中心的四分之一格采样。两套格网中的重复塔位只计一次，保持剩余域及前向约束计数正确。每个新增候选仍执行原来的真实三维覆盖、原型碰撞、带/分拣器净空和塔距检查。

实际失败快照中的分拣器415，其周围存在纬向坐标约18.60的可建窄缝。旧版快照测试失败，修复后找到61个合法塔位；同一场景中确实被封住的分拣器4798仍被拒绝。局部采样修复没有放宽几何规则。提前为生产单元预置电塔的试验使中心案例包络增加约25%，已撤下。

第1至4档大厂的设施模式现在在南北两侧边缘均比较相差180度的球面刚体候选。机器保持当地经纬正交，半球、位置、槽位及完整连接仍重新验证。直连模式保留固定左侧原料入口。

## 回归与证据

148组完整生成回归通过：27位置四模式矩阵240、极区六位置四模式制造台Mk.II 30（硅石原矿）、赤道/北极中心四模式矩阵480及两处四模式磁线圈抽查。算法包338.580秒。480矩阵赤道中心直连25×40、星际塔29×42且1塔，北极中心星际塔仍为1塔；实际几何图已复核。

`go build ./...`与`wails build -s -skipbindings -m -nosyncgomod`通过，更新`build/bin/DysonSphereBox.exe`。验收通过临时Go overlay执行，清理后仓库直接运行测试不会重建这些用例。
