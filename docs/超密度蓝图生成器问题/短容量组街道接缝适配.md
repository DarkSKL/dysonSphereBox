# 短容量组街道接缝适配

2026-11-09，基于 `9f2db6f`。本阶段继续处理运输船60/min完整链在窄纬带中的排布，修复缩短机器容量组后过早出现的街道接缝失败；整厂球面装箱仍未完成。

## 改动

旧接缝搜索只允许额外1格机器间距、±0.5格传送带相位。部分短容量组需要更大的合法接缝，在进入全场装箱之前就被拒绝。

现在先完整执行原搜索；仅当全部失败，才把间距搜索扩到一个该机型的重复周期、传送带相位扩到±1格。扩展搜索跳过已经检查的组合，首段不额外平移。已通过原搜索的布局直接保留。

机器、分拣器、必要货物采样节点及独立物料轨道均保留。每个候选继续执行0.35米节点净距、真实货物采样、带长、静态与动态几何检查，返回街道前仍核对逐组机器数和所选分拣器能力；取消仍使用同一生成上下文。

逐轨道相位、优先放塔、优先高单元和减小经向接缝预留等试验未解决完整链装箱，均未进入产品代码。也未提交缩短大厂默认分组的试验，避免把仍然失败的整厂候选当作解决方案。
