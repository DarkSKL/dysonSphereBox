# 共享原料塔口与采样保护验收

2026-11-09，基于 `b93493e`。塔模式原先没有启用外部原料的共享消费轨，同种原料的多个容量组各占一个塔口。本阶段增加独立共享候选，并修复串供转弯改变末端货物曲线的问题。

## 正式生成结果

运输船60/min在第二档北半球中心通过公开`Generate`入口，保留全部937台原等级生产设备和原物料链，物流塔由7座降到4座，占地由784×28降到783×26，实际总带长由72,290.589米降到68,901.359米。占地减少约7.3%，带长减少约4.7%。赤道中心运输船保持342×61、7塔及原带长。

| --- | --- | --- | --- |
| 运输船60/min，第二档北半球中心 | 7→4 | 21,952→20,358 | 72,290.6→68,901.4 |
| 电磁矩阵480/min，赤道中心 | 1→1 | 1,189→1,056 | 861.4→715.8 |

最后一例以较长线路换取更小面积。塔数相同时，共享原料候选沿用新增同线炼油候选的综合比较：保留长条惩罚，比较空间目标与真实带长的乘积，避免用很小的面积收益换取明显绕线。76份回归中有16份包络缩小，没有包络或塔数增加的案例，完整逐例数据在证据包中。

## 实现

共享方案作为独立候选加入原有搜索，保留已有成功布局参与比较。仅在具备真实黑盒边界的行星塔、星际塔模式中共享无喷涂原料；每组仍按全部消费者的配置满负荷需求限制单带容量。原生候选使用真实原型占地，不更换设备、减少机器或外供中间产物。

最终核验分别登记规范物流份额和物理供给。多份规范原料可以使用同一个真实塔口，但必须属于同一已提交的供给对象、消费者组、物品和塔边界；份额总和必须等于物理塔口流量，且有真实来源归属。公共物流终检继续逐组重放完整串供链、全部消费者输入轨和配置毛流上界。

实际失败记录中，炼油输入带尾承担参考分拣器取料，直接接入转弯会改变该节点的Bezier货物曲线。同一目标在完整线路中的最近采样误差为0.100225米，临时断开轨道外连接后为0.022987米。增加一个沿原方向延续的真实带节点后，完整线路的误差降到0.023102米；允许误差仍为0.080000米。

只给仍需连接下一消费者、且参考取料点靠近带尾的轨道添加该节点。新增节点参加实际单元占位、货物轨登记和最终几何检查，不为最后一个消费者添加无用串供尾巴。

## 验证

- 74组公开生成回归通过：矩阵240/min覆盖27个地区选项×直连/星际塔两模式，共54组；360/min第三档北半球南侧两组；480/min四组；600/min开启检测器四组；硫酸120/min两组；制造台Mk.II 30/min南北极点侧×四模式，共8组。制造台以硅石直接作为原矿，保持95台原等级设备。
- 两份运输船60/min完整937台链通过公开生成。以上76份均严格解码，核对机器与配方数量、带和臂的等级、机器正交Yaw及零Pitch/Tilt，清除已有检查标记后重放最终静态、动态、接线、真实纬界和供电规则。
- 综合代价调整后，受影响的34组小厂塔候选再次生成并复核。
- 在完整4塔运输船实例上，8项反例均被拒绝：篡改规范份额、塔口流量、归属、塔边界，冒充另一物理供给，未提交网络，断开真实串供带，以及配置负载超过带容量。恢复原数据后通过完整共享网络和塔口核验。
- 预览协议3、4分别验证普通球面和原生球面场景，最终预览各提交一次；协议4登记的候选数分别为13、10，获选候选身份和事件顺序有效。候选计划发布时取消，不返回成功蓝图。
- 失败货物曲线的独立反事实检查验证了新增一个节点后的采样误差和带距离。它只证明局部曲线修复，不作为另一份完整蓝图验收。
- 已查看6张原生几何投影，包括运输船全图及东西两段局部、480矩阵、第四档240矩阵和南极侧制造台。图片来自最终记录和实际原型盒，不是游戏截图。

`go build ./...`、`wails build -s -skipbindings -m -nosyncgomod`与`git diff --check`通过，已更新`build/bin/DysonSphereBox.exe`。本阶段没有前端或Wails绑定接口变更。

## 证据与交付边界

[共享原料塔口与采样保护证据.zip](共享原料塔口与采样保护证据.zip)保存正式请求、结果、可导入蓝图、布局图、曲线原始记录、逐例比较和验证日志。已核对357项ZIP内容的CRC、356项登记文件指纹、678项源码指纹及程序指纹。

程序指纹对应整个构建工作区，其中包含工作区已有的`helper/factory/progressjournal/store.go`改动；该文件不纳入本阶段提交。临时Go测试通过overlay运行，证据包不包含测试源码、试验实现、测试可执行文件或性能剖析文件。

确认全部测试进程结束并核对归档后，本轮专用临时目录中的578项文件和两个子目录已移入回收站。

第三档运输船完整链仍在装箱阶段失败。第四、第五档运输船全链及其它尚未覆盖的模式继续属于原目标。第二档运输船仍是沿纬圈展开的长矩形，尚未达到更充分利用纬向空间的目标。后续应继续核对临时平面包络是否提前限制了原生纬向预算，并改进整档范围内的实体装箱。

四物料局部单元、按失败配方逐次细分容量组、经向优先选址及半周旋转等试验未生成第三档完整工厂，没有进入产品代码。证据包将其放在`research`和`failed-diagnostics`下，诊断程序的PASS不代表其中的装配成功。

碰撞原型版本为0.10.35.29151，量化数据版本为0.10.34.28524。实际游戏铺设、运行时环境和持续生产尚未实测，完整五档目标保持进行中。
