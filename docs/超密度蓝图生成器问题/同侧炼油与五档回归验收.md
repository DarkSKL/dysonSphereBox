# 同侧炼油与五档回归验收

2026-11-09，密度规则版本`dense-v7-spherical-refinery`。

炼油厂新增同侧三条独立地面轨道，机器保持当地经纬正交朝向，重复节距3.15格并叠加用户额外间距；容量组按实际模板节距细分，保留原设备等级、总数及全部物料。原油输入、氢输出、精炼油输出使用各自的真实带链与槽位。

来源为teapot发布的[前期-炼油厂](https://www.dsp2b.com/zh-CN/blueprint/69712114457e2a9f4f2d9777)。内嵌原始13条记录，严格校验MD5F和SHA-256；来源版本为`0.10.33.27026`，使用时按当前原型、槽位、动态几何及货物采样重新核验，不把来源版本当作最终兼容性证明。来源SHA-256为`ab22cf7e5d8cdf44062fa9e555e29e3ec5fab47bc0f5807074600f94be5d7f02`。

该模板用于无喷涂、无流速监测且所选单臂能力足够的等离子精炼；其它请求继续使用原有局部候选。来源offset只用于还原原货物取放点，生成后在同物料实际轨道重新绑定。

## 球面适配

- 从当前原生建造盒计算Yaw零度外包，随记录Yaw旋转，避免把旧270度炼油厂的短纬向估算套到新长轴上。
- 主体带采用不超过1.5格的节点间距；第4档及原生子环按本带最宽、最窄处的格距比例提前收紧，极区跨环沿用真实球面重采样。第4档北边缘的2.468米超长段已被拦截并修正，2.302米限制没有放宽。
- 极区同时保留同侧、分侧两种密铺局部拓扑，并执行同样的完整终检。贴极点的混合产线可选择适合该位置的局部形状，整体仍采用对外共享设施、内部直连的布局。

## 已完成的离线检查

`go test`通过临时overlay加载验收源码，10项顶层测试及521项子测试共531项通过，算法包508.172秒。临时测试源码在验收后清理，下面是本轮执行记录，不代表当前仓库直接运行测试会自动重建这些用例。

- 精炼油360/min：27个地区、四种运输模式，共108组完整生成。严格解码，核对12台炼油厂、实际区域、正交朝向、槽位、独立带链、原生碰撞、货物、能力及供电。
- 局部单元：一级/四级分拣器，1、2、5、12台机器组合；货物重绑、带长、静态与动态几何通过。四个排向的宽高预算覆盖真实建造盒。
- 第5档原有144组案例：矩阵240/480、带监测器的矩阵240、制造台Mk.II 30（硅石原矿输入）、电路板与磁线圈；保留全部生产机器，检查导出后的正交朝向。
- 既有第1至4档、360/min一级物流反馈、边界物流、监测器方向及端点回滚继续通过。
- 重新生成赤道中心及第5档北极区中心的480/min矩阵，均为1座星际塔；已按Go导出的真实盒和端点重新绘图、人工复核。
