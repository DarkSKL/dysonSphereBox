# 600/min电磁矩阵空间预算与真实纬界修复

2026-11-09，基于 `8e3cd25`。本阶段修复600/min电磁矩阵频繁出现「全场密铺在本次空间预算内未找到可接线的实体位置」，并处理相邻的真实建造盒纬界与流速检测器宿主问题。

## 实现

原生球面排布只固定所选纬带的纬向高度，经向预算按实体占地估算。此前第2档会把经向搜索也限成相同宽度的正方形，导致仍有经向空间却提前报告无位置。

第1至3档的小型密铺若在临时平面装配中遇到可重排的几何错误，撤回失败预览，再按目标球面重新排布。已有成功布局保留；取消、未知原型、设备能力不足等不会被当作几何失败重试。

原生候选全部失败后，才启用一次真实原型建造盒占地细化。先前无条件细化曾让部分合法布局变大，最终实现保留原候选优先级，不通过修改产量、配方、设备等级、带速或外供中间产物取得成功。

正式导出及重定位安全范围检查均增加静态建造盒八角点的球面纬向检查，避免粗略格数在档位内、实际建筑却跨入相邻档位。投影保留0.01格、约1.3厘米的数值容差；实体碰撞、带节点净距、货物采样、分拣器和供电规则没有放宽。

流速检测器绑定实际宿主带的实体引用；裁剪保留宿主及其前后带邻居，迁移附件时同步引用，最终校验拒绝换绑。不同局部行在全场排布前可能坐标相同，不能只按坐标猜宿主。检测器本身也使用真实原型占地；最终朝向继续由实际有向带的球面切线计算。

## 验证

600/min使用界面默认的1级传送带、1级分拣器、堆叠上限3层、无喷涂，共79台生产设备；前端已剔除的平面专属布局参数保持未设置的零值，由后端正常归一化。

- 五档共27个位置，包含中心及南北边缘，四种运输模式共108组，全部由公开生成入口成功生成。逐份严格解码并复核实际设备、配方、产量约束、正交朝向、带长、静态与动态碰撞、分拣器跨度、供电及真实静态盒纬界。
- 改动前相同108组有40组生成失败；68组返回结果中，24组真实静态盒越界，44组合法。最终实现保留这44组的包络面积，没有面积增加。
- 电磁矩阵240/min共54组，480/min共4组，360/min第3档北半球南边缘共2组，硫酸120/min抽查2组，600/min开启检测器4组，共66组生成及几何回归通过。
- 制造台Mk.II 30/min，南北极点侧各四模式，共8组通过；全链95台原等级设备，硅石直接作为原矿输入。
- 检测器四组均核对原始宿主身份、完整带邻居和实际带流方向。独立世界坐标方向检查的余弦大于0.99999。重复局部坐标的宿主裁剪用例通过，并确认无用带尾仍会删除。
- 重试路径的预览协议3、4及取消用例通过。原越界蓝图被新出口规则拒绝；另两份原生成失败的对照没有蓝图，相关拒绝检查跳过，未计为通过。
- 上阶段937台运输船赤道中心、第2档北半球中心的两份有效蓝图，使用当前源码重新解码及执行原生规则复核通过；本轮没有重新生成这两份。
- 已查看六个600/min边缘或极区样例和一个检测器样例的真实建造盒、世界端点与连接投影图。图片是离线几何投影，不是游戏截图。

`go build ./...`、`wails build -s -skipbindings -m -nosyncgomod`与`git diff --check`通过，更新了 `build/bin/DysonSphereBox.exe`。Wails构建复用已有前端产物；本轮未修改前端或绑定接口。

## 边界与剩余目标

碰撞原型来自游戏版本0.10.35.29151，量化计划数据标记为0.10.34.28524，证据保留各自版本。以上是当前数据下的离线验证，游戏内实际铺设与持续生产尚未验证。
