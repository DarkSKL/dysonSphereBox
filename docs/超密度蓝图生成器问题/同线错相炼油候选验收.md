# 同线错相炼油候选验收

2026-11-09，基于 `e72c91e`。本阶段继续压缩大型产线的局部运输开销，尚未完成第3至5档937台运输船的整厂验收。

## 实现

为无喷涂、无流速监测的等离子精炼增加独立塔模式候选10至12。三种物料使用三条独立地面传送带，沿同一条局部轴线错开三分之一个节点周期；主体步长上限1.5格，跨纬度后仍按真实米制距离补点。尾端保持相位，入口保留额外两格直线，防止接线转弯侵入首台机器的货物采样窗口。

带侧端点按已核对的炼油厂槽位调整，跨度参数从实际两端重新计算，再执行所选等级的逐物料能力检查。机器数量、型号、配方、原料及产量均不改变；节点合并阈值、0.08米货物误差、静态盒、动态盒及供电规则保持。

原候选完整保留。塔数仍优先取少；新增候选还须通过原空间评分，且不能扩大包络面积，再以形状代价与实际带长的乘积比较，避免用小幅面积收益换取大量绕线。原候选之间的评分不变。

## 验证

- 精炼油120/min与硫酸120/min：各27个位置、行星塔与星际塔，共108份完整链蓝图。逐份严格解码，核对设备、配方数量和正交朝向，并独立重跑带长、静态、动态、分拣器跨度和供电规则；全部通过。
- 与改动前源码生成的108份同请求结果逐份比较，包络面积无增大。最终5份第3档硫酸星际塔蓝图采用新候选；其它请求继续选择更合适的完整候选。
- 炼油局部：1至32台、1至4级分拣器，共128组，局部静态、动态、真实货物采样及逐物料能力检查通过。
- 空间与走线评分：4个回归案例通过，包含拒绝“面积减少约6%、实际带长增加约40%”的候选。
- 480/min电磁矩阵：赤道中心与北极中心，四模式共8份；制造台Mk.II 30/min：南北极点侧，四模式共8份，硅石直接作为原矿输入。16份均已完成生成及最终源码的独立解码复核。初次组合验收达到测试容器8分钟上限，剩余两项单独执行通过，未将容器超时当作蓝图成功。
- 937台原等级设备的运输船60/min：公开入口复验赤道中心和第2档北半球中心，仍为342×61及784×28；完整解码与当前原生规则复核通过。
- 已查看第3档边缘、第5档中心和赤道样例的真实建造盒、世界端点与连接图。图像为导出几何投影，不是游戏截图。

第3档北半球南侧硫酸星际塔案例：包络561→493，减少约12.1%；传送带351→341，实际带长496.38→493.77米。其它四份新候选的包络减少约5.6%至6.7%，实际带长小幅增加，综合代价通过比较。第5档曾出现绕线明显增加的候选，最终评分已将其排除。
