# 四物料化工与第4档原生坐标验收

2026-11-09，基于`f2898c0`继续开发。运输船第3档的完整链尚未通过，本阶段交付可独立复核的化工局部能力和选区修复。

## 实现与边界

为三输入、一产物的无喷涂化工配方增加独立塔模式候选。中央三轨继续采用用户`73125增产剂v1.3（本地版）`的参考双排，第三种原料通过另一侧真实槽位接入单独的U形外轨。化工端口两侧不对称，反射中心按已核对的实际槽位位置计算；两排之间采用真实高架过渡，转弯前保留三格平直货物采样邻域。

候选逐台创建第四根所选等级的分拣器和独立物料带，重新绑定真实货物目标。机器型号、数量、所有原料及输出保持原计划。局部原型、单臂能力、静态盒、动态盒和货物采样全部继续核验。当前限无喷涂、无流速监测；其它请求继续使用既有候选。

新候选作为独立编号7至9加入原有塔候选比较，通过完整生成与终检后才参与选择。容量组按双排真实节距细分，不扩大带容量、不突破用户单行上限、不引入逐物料塔转发。

同时修复两处选区问题：赤道中心也执行正交映射，避免小型硫酸产线出现机器偏转；第4档统一在目标原生球面落位和接线，避免在临时坐标中误拒绝可建小厂。

## 已完成的离线验证

- 局部化工单元：1、2、6、12台机器与1级/4级分拣器，共8组，独立静态、动态、真实货物采样及物料数量检查通过。
- 硫酸120/min完整链：9台原等级设备，27个位置、行星塔/星际塔共54组，全部严格解码并核对逐配方数量与正交朝向；其中15组最终选用新增四物料单元，其余采用比较后更合适的有效候选。
- 既有148组：矩阵240覆盖27位置四模式，极区制造台Mk.II 30采用硅石原矿输入，480矩阵两处四模式，以及磁线圈抽查。480矩阵赤道中心直连25×40、星际塔29×42且1塔，北极中心星际塔仍为1塔。
- 已复核赤道、第3档边缘、第4档边缘及第5档边缘的硫酸真实几何图，以及480矩阵基线图。图形来自实际导出记录、原型盒和世界端点。

本轮共210组子测试及3项顶层测试通过，算法包346.339秒。`go build ./...`和`wails build -s -skipbindings -m -nosyncgomod`通过，更新`build/bin/DysonSphereBox.exe`。

追加复验两份937台默认设备的运输船60/min完整链：赤道中心仍为342×61；第2档北半球中心选用四物料候选后变为784×28，相比此前783×36包络面积减少约22%。两份都在严格解码后按当前源码重跑完整原生几何、货物端口和供电规则，逐配方数量、等级及正交朝向保留。已复核改善案例的整体和局部实际几何图。

基线对照中，赤道硫酸星际塔出现机器偏转，第3档北半球南边缘星际塔和第4档两处塔案例未通过；本阶段对应案例通过。生成与碰撞证据不作为实际游戏铺设和连续生产证据。
