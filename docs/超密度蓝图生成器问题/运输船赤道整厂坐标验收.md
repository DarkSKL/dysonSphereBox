# 运输船赤道整厂坐标验收

2026-11-09，基于`a6bfeda`继续开发，密度规则仍为`dense-v7-spherical-refinery`。本阶段解决大厂在目标球面映射之前被临时锚点碰撞拒绝的问题；五档运输船整体验收及游戏内铺设仍未完成。

## 实现

256台以上的超密度产线从局部单元落位开始固定目标球面坐标，后续寻路、端口适配、供电及编码使用同一坐标。原生主区编码由第5档扩展到实际选定档位；前三档小厂保留既有生成路径。

非极区按局部单元总包络及本档纬向高度估算有限的经向预算，中心位置从中间向两边装箱，南北边缘向内装箱。原生终检同时检查所属档位和所选位置，偏离中心或边缘也会失败。没有修改碰撞盒、带长限制、设备等级、产量或原料链。

## 已通过的运输船完整链

原版默认配方、运输船60/min、硅石作为原矿，带等级3、分拣器等级4，无喷涂。每份均保留937台生产设备；导出后严格解码，按实际记录复核机器数量、当地经纬正交Yaw和零Pitch/Tilt，并生成真实原生盒及世界端点图片。

## 回归与构建

- 148组完整生成通过：矩阵240覆盖27个位置及四模式（108组）；制造台Mk.II 30、硅石原矿输入覆盖极区6位置及四模式（24组）；480矩阵覆盖赤道/北极中心及四模式（8组）；磁线圈360在第4档北边缘、第5档南极边缘抽查四模式（8组）。检查严格解码、逐配方机器数、正交姿态和实际纬带范围。算法包341.983秒。
- 三份运输船蓝图的位置反例检查通过：偏离所选位置、超出赤道环均被拒绝。
- 480矩阵赤道中心直连25×40、星际塔29×42且1塔；北极中心星际塔仍为1塔。四张直连/星际塔真实几何图已复核。
- `go build ./...`和`wails build -s -skipbindings -m -nosyncgomod`通过，更新`build/bin/DysonSphereBox.exe`。

[运输船赤道整厂证据.zip](运输船赤道整厂证据.zip)保留有效蓝图、完整量化/生成请求、生成结果、世界几何场景、图片、验收日志和源码/可执行文件指纹。临时overlay验收源码在验证后清理，仓库直接执行`go test`不会自动重建这些用例。图片可用`scripts/blueprint/render_native_scene.py`从包内场景重新生成。

归档后已核对ZIP CRC、全部登记文件哈希、当前源码及可执行文件指纹；本轮临时目录的61项测试源码、失败试验及中间文件已移入回收站。保留生产功能和验收必需的数据、图像及蓝图。

## 未通过与后续

运输船赤道中心的直连、配送器模式及第2档北半球中心星际塔仍失败，失败日志单独归档。直连的原生候选在空间搜索阶段失败；第2档的可路由候选仍存在供电合法域不足，另有局部端口接驳失败。一次相邻带头直连试验未解决问题，已撤下。

运输船第2至5档完整链、其余运输模式、外供lane合并及整体线路占地仍需继续优化。游戏进程本轮未运行，实际游戏铺设与连续生产尚无证据；离线原生规则通过不作为游戏实测通过。
