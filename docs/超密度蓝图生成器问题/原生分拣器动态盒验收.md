# 原生分拣器动态盒验收

2026-11-09，基于 `b128fbb`。本阶段修复原生球面装箱中分拣器预筛选过度拒绝的问题；第三至第五档运输船60/min完整产线目标仍未完成。

## 实现

原装箱把分拣器两个端点之间的线段扩大为0.5米距离邻域，会拒绝一些实际动态建造盒互不相交的位置。现在从正式分拣器检查中提取共用的世界坐标入口，原生单元可使用同一套槽位修正、角度、跨度与动态盒公式。

既有装箱及纬向修复全部失败后，细化阶段才使用真实动态盒。只有连接两端都属于同一刚性单元的分拣器可以使用该结果；未闭合单元以及完整、未闭合单元之间仍保留原粗筛。单元内部动态盒相交、未知几何、错误端口和取消均不能当作有效结果。

经度移动同时旋转盒中心和三个方向轴；纬度移动后重新计算动态盒。大厂的某个纬度遇到可重排几何错误时继续检查其它合法纬度，未知错误及取消直接返回。最终编码仍执行原有完整规则，未放宽碰撞、分拣器偏角、带长、塔距或纬带边界，也未修改设备、产量与物料链。

## 验证

- 27组新旧正式动态盒对照通过：三份完整工厂各九组原始或扰动记录，盒、跨格参数和错误结果逐项一致。原生单元与最终编码分别核对2594、178、246个分拣器盒，结果一致。
- 从已有可用运输船工厂提取的12个真实误拒绝见证全部通过：原粗筛移动或拒绝，真实动态盒保留原合法位置。真实内部碰撞仍拒绝，未闭合引用不猜测，混合单元不跳过粗筛。
- 经向刚体移动后的盒与重新计算结果最大分量差为0.000013009；缺少球面坐标、端点数组数量不匹配及取消检查通过。
- 74组公开生成回归通过：矩阵240/min共54组、360/min共2组、480/min共4组、开启检测器的600/min共4组、硫酸120/min共2组、制造台Mk.II 30/min南北极点侧四种模式共8组。制造台保持95台原等级设备，并以硅石直接作为原矿。
- 运输船60/min完整937台链在赤道中心和第二档北半球中心重新生成，保持342×61和784×28。
- 以上76份均严格解码，并核对配方与机器数量、设备等级、机器正交朝向和零Pitch/Tilt；清除已有检查标记后重放静态盒、分拣器与其它动态规则、连接槽、带长、真实静态盒纬界及供电。相较上一阶段，全部包络面积、塔数、带与臂的类型和数量、总带长均未变化。
- 已查看第三档600/min矩阵、南极侧制造台和第二档运输船的真实几何投影。图片来自最终记录、世界端点与原型盒，不是游戏截图。

`go build ./...`、`wails build -s -skipbindings -m -nosyncgomod`及`git diff --check`通过，已更新 `build/bin/DysonSphereBox.exe`。本阶段无前端和绑定接口变更。
