# 球面装箱索引优化验收

2026-11-11，接续候选连续调度阶段 `671d31f`。本阶段仅优化球面装箱的计算开销，运输站整体超时仍待后续寻路优化解决。

## 变化

球面装箱按原检测顺序逐个旋转实体，遇到第一个碰撞即停止当前位置，避免预先变换整组静态盒、带节点及分拣器。空间桶命中后，用登记时保存的世界包围盒再次筛选，减少同桶内无关对象进入精确检测。保留原有毫米外扩、定向盒交叠、节点距离、分拣器和设施间距规则，候选位置顺序及成功后的实体提交方式不变。

这里沿用“空间索引缩小候选、窄相位决定真实碰撞”的方法；可参考原始论文 [Optimized Spatial Hashing for Collision Detection of Deformable Objects](https://cgl.ethz.ch/Downloads/Publications/Papers/2003/Tes03/Tes03.pdf)。本实现不移植论文的四面体碰撞公式。

## 验证

- 60/min 行星物流运输站，硅石直接外供、一级设备、传送带模式、赤道中央，2807 台生产设备。旧版前 10 个候选装箱阶段为 149404–165369 ms，优化后为 38537–43632 ms；中位数 162776 → 42178 ms。两次整图生成均在四分钟时限内失败，因此不能把装箱提速报告为整图生成成功。优化运行期间另有一个单工作槽对照测试，时间仅作为本机观测，不作为严格统计基准。
- 从提交中的旧装箱函数和旧空间索引生成独立对照，分别执行电磁矩阵 3000/min 赤道中央及第三档北半球南侧、能量矩阵 1000/min 赤道中央、行星物流运输站 6/min 赤道中央。每次装箱的错误、阻塞单元及所有实体字段均与新实现相等；这些是装箱阶段对照，不代表四个案例的整图生成或游戏拍建验证。
- 随机生成 1200 个旋转盒，对 2000 组盒查询和 2000 组节点查询与全量精确检测逐项比较；验证查询标记回绕，全部通过。
- 完整回归：1500/min 能量矩阵、研究站三层、一级带/臂、赤道中央，启用 v4 预览和逐事件序列化，132899 ms 成功，30321 个建筑。解码后全部建筑及区域与前阶段 124899 ms 的结果逐项一致；该案例未观察到整体提速，不作相反宣称。
- `go build ./...` 通过。没有新增外部依赖或改动绑定签名。

同目录 `球面装箱索引优化证据.zip` 保留旧实现对照、测试、性能摘要及完整回归的相等性结果。未执行游戏内拍建。下一阶段的主要热点是长路线的重复有界 A* 搜索，不应通过延长超时或缩减目标产能掩盖。
