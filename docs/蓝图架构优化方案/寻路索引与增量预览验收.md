# 寻路索引与增量预览验收

2026-11-11，接续 `6c78463`。本阶段修复已记录的运输站及能量矩阵超时，并继续推进 60/min 运输站的完整性能目标；后者尚未完成。

## 实现

- 整数运输网格以无冲突的 48 位键索引访问状态；分数坐标、非有限或范围过大的搜索沿用原坐标表。精确分支先跳过关闭节点，避免重复查占位、整段净空和软代价。
- 同一平面位置中，被其它后缀同时支配代价和长度下界的项不再参与每个节点的启发式计算。全部真实终点及其权限仍保留，目标并未删除。
- 非严格带碰撞的原生球面网格，在平面搜索域达到 16384 格时使用权重 2 的有界代价搜索，允许更低代价重新打开节点。只有剩余开放队列的估计值证明单次主路及目标后缀的代价界，或队列耗尽时才交付；预算用尽但界未证明时不返回该结果。其它网格保留权重 1。四分钟期限、300000 次展开、32 层高度、物流容量、球面及终检规则不变。
- 完整路线的自身净距检查改为空间索引，避免逐对重复计算球面坐标；短路径仍直接比较，所有距离和容差不变。
- 直连路由开始前完整同步已冻结的端口，之后每次路线提交只发布新增带节点及改变了输出连接的源端。追加前置条件不成立时回退完整同步；其它平移、删除、回退及最终快照仍完整处理。过程事件不丢弃、不截断建筑。

有界搜索采用加权 A* 的思路，参见原始论文 [Faster than Weighted A*: An Optimistic Approach to Bounded Suboptimal Search](https://cdn.aaai.org/ICAPS/2008/ICAPS08-044.pdf)。本实现使用固定权重和开放节点重新松弛，没有移植论文的两阶段 optimistic search；单次整数主路的界不等于整厂全局最优。

## 行为与构建检查

- 220 组整数/分数坐标、重复目标、合流权限、占位及走廊用例，与旧精确搜索器的路径、终点下标、展开次数逐项相同；覆盖编码边界及父取消。
- 400 组目标集合、每组 100 个查询点，下界支配消除与全部目标计算相符；浮点成本误差上限 `1e-10`，长度相等。
- 100 个小网格有界搜索与旧精确搜索对照，返回路线逐步合法、无已知阻塞点且满足成本界。
- 400 组路径净距查询与直接全量比较一致，另含空间桶边界及净距临界值。
- 协议 3 和 4 各 918 次真实路线提交：每次增量发布后立即执行完整同步，未产生任何补充操作。独立通知器检查同时覆盖分批、帧变化、终结缓存和最终状态相等。
- 封闭区域微基准三次：原搜索 110–140 ms，新索引 49–55 ms；分配约 18.4 MB → 12.6 MB。这是局部基准，不替代整图指标。
- `go build ./...` 通过；没有变更绑定签名或增加外部依赖。

同目录 `寻路索引与增量预览证据.zip` 保存测试源码、对照实现、性能摘要和回归输出。临时测试未注册为生产入口。

## 仍在推进

60/min、2807 台设备的一级带运输站仍未生成成功。新搜索暴露出多候选在完整物料布线中超过现有 200000 建筑上限；仅在临时覆盖层中提高上限的实验继续发现后续物料端口被已铺路线封闭，最终仍超时。该实验峰值工作集约 7.7 GiB，不能直接并入正式版本。

平面走廊优先、简单依赖顺序装箱和扩大装箱纬向比较的临时实验也未完成此案例，均未纳入本阶段提交。后续须协调端口通道预留、实体规模和内存预算；不得将 30/min 成功替代目标中的 60/min，也不通过延长截止、降低产能或跳过终检宣布完成。
