# 生成反馈与完整可视化验收

2026-11-11，基于`0269e51`。本阶段只调整生成提示与算法可视化，不修改布局、配方、输送能力或放置校验。

## 生成反馈

桥接状态沿用稳定错误码，增加可选`suggestion`和`detail`。超时、接线、超密度布局、地区容量、带臂能力、供电、碰撞和连通检查等常见失败改为简短中文原因；处理建议单独展示，完整包装错误保留在技术详情中。未识别的错误及原有量化、解析提示保持原文。成功状态不额外发送空字段。

生成失败弹窗与页内提示复用同一组件。默认展示原因和建议，技术详情可展开、滚动和选取，后端文本通过插值显示。长诊断在窄窗口不会覆盖按钮或造成横向溢出。

候选比较阶段的状态栏不再重复显示计数，也不直接铺开长接线诊断。单候选失败说明为继续比较，原始原因保留在事件`detail`中；阶段、真实计数和序号不变。预览差量、候选开始等画面事件不再覆盖工作区的真实生成阶段。算法阶段文案可悬停查看原诊断，调试时间流仍保留完整载荷。

## 完整回放

移除工作区的前12000条截断及其提示；渲染包默认上限改为无限，应用不再传入数量上限。库仍允许其他调用方显式设置单平台上限，当前应用使用完整展示。实例池继续按实际用量增长，模型和原始建筑记录均不按数量阈值删减。

结果回放先为全部建筑建立身份索引，再转换跨批传送带引用。索引、差量比较和入队均分批让出主线程；每次恢复都检查请求版本，旧任务不能继续覆盖新结果。清空结果或切换回实时跟随时同步清除解析状态。大场景切换来源时直接清空并复用实例池，避免为已经过期的全部建筑再安排退出动画；小场景保留退出过渡。

跳过动画仍受共享4毫秒/1024项帧预算约束；单队列不再额外受128项限制，有并发候选时保留轮转份额。积压期间减少中间GPU重绘及重复边界计算，完成帧立即完整绘制。尺寸调整和立即换主题使下一次重绘立即生效；FPS统计按真正绘制的帧数计算。

## 跳过后的持续卡顿

用户补充“跳过后卡顿，重新回放后恢复”。最小复现确认旧实例池在淘汰后留下绘制空洞：10000个槽位只保留1000个有效实例，GPU仍按9991个槽位绘制。多候选交错分配后仅保留获选方案，实际绘制与拾取范围可能仍接近搜索峰值；重新回放会重新排紧，因此工作量明显下降。

实例池改为连续存放活动实例，释放时把末端实例及其矩阵、全部自定义属性补到空位；场景同步更新建筑、阴影与涟漪的槽位和拾取身份。矩阵容量仍可复用，绘制数量立即降至有效数量。销毁同步移除闪白引用，退场高度未变化时不再重复更新整候选；没有活动动画时直接返回，避免获选方案静止后每帧扫描全部建筑。
