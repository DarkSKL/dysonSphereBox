# 三层边界接口与带段隔离验收

复现配置：60/min 信号塔、传送带模式、超密度、一级传送带及一级设备，石矿制硅。完整生产计划与修复前一致：PlanID `12e0254f66365480bd59a8f2111b0090`，377 台生产设备。

## 修复行为

原入口位置先按单层排队拉长，再拿这个已经拉长的位置适配整条纬带；输出又固定从纬带底部开始排。新的联合边界计划直接读取真实消费者和生产实体的纬向包络，地面输出按生产者位置就近预留，原料在 0、2、4 三个带高度分配独立槽位。优先两格行距；容量需要且未开启流速监测器时允许一格行距，输出周围仍保留两格隔离。

原料头通过短直带向内接入，固定前缀保留唯一原料头身份和完整有向连接。模型盒外留有短接驳空间：平直接口限定三层，向厂内的升降过渡遵守原有高度和真实碰撞规则。整个接口区（含升降过渡）检查独立节点与带段相交，最终从实际实体重建检查，不能把同坐标的独立节点冒充合流。

接线前保护每个原料头向内两格的出路；先安排厂内受限端口，再按低层至高层接入外供。只改变接线顺序，不改生产量、配方、单带容量或物料份额。其它运输模式和普通模式不启用本计划。

## 实际结果

| 包络面积 / 格² | 15,553 | 6,762 |
| 传送带数 | 11,937 | 10,120 |
| 总带长 / 米 | 17,405.98 | 15,092.08 |
| 全部实体数 | 13,220 | 11,402 |
| 物理原料入口数 | 40 | 40 |
| 接口纬向坐标范围 | 0–102 | 1–43 |

占地减少 56.5%，传送带数减少 15.2%。逐规范边核对原料、成品及副产物流量完全相等。最终生成 14.345 秒（该轮同时运行大型回归，不作为隔离性能基准），真实日志写入/回读 8,422 个预览事件，序号连续且无丢失。

回归均经过公开 Generate、严格蓝图解析以及 Buildings/Areas 编码往返比较：

| 配置 | 结果 | 实体数 | 记录耗时 |

## 验证范围与复核

- 小规模槽位分配与独立穷举最优解比较 100 组；容量耗尽和取消正确返回。
- 注入同层交叉、同坐标假合流、第四层入口、纬向长尾、向外回绕等错误均被拒绝；正常跨层、真实共享端点和合法升降通过。盒外过渡允许升降但仍拒绝交叉。
- 固定前缀的真实外供头身份、有向连接、有限出路预留、厂内及同层接线保序均通过检查。
- 预览协议 v3 / v4 各核对 918 次实际追加，追加后再做全量快照，无额外变更。
- 使用项目真实模型在算法可视化中加载修复前后全部实体，完整渲染、末对象选择和零积压检查通过；人工查看截图确认上下长尾消失。采用软件 WebGL，截图与帧率不代表用户显卡性能。
- `go build ./...` 与 `wails build -m -nosyncgomod -skipbindings` 通过；Wails 构建包含 frontend 的 `vue-tsc --noEmit` 和 Vite 生产构建。无绑定签名变更。
- 尚未在游戏内实拍验证；离线几何和真实模型预览不能代替游戏场景验收。
