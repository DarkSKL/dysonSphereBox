# 候选连续调度与即时退场验收

2026-11-11，基线 `b54808a`。本阶段处理空闲计算槽等待、已淘汰候选积压和错误来源覆盖；60/min 行星物流运输站的完整性能优化仍在进行。

## 实现边界

- 大型原生超密度直连候选改为连续派发，空闲工作槽立即接下一个候选，仍保留原并发上限。全部在途任务退出后按原索引归约；父请求取消不交付结果。首个完整可用结果后的五秒比较窗口和原生成期限不变。
- 候选实际开始才建立平台；失败、剪枝或确定落选后立即清空其待播队列及快照，复用下坠效果并分帧回收。暂停演示也会执行淘汰回收；同任务的迟到入队不能复活已淘汰候选。
- 前端持续读取有序过程事件，不再以待播操作达到 20000 条为理由阻塞后续淘汰通知；连续补页之间让出主线程。活动候选和最终获选快照仍完整校验、完整显示。
- 后端候选结束后释放差量镜像，获选正式快照独立保留。球面重试发现上下文结束时保留原始失败，避免下一次准备把原因覆盖为“配置能力重算”。

## 尚未解决

1500/min 能量矩阵的一层研究站配置仍在四分钟期限内失败，错误已保留为原阶段的“蓝图预览事件输出超时”。60/min 行星物流运输站（硅石直供、一级设备、传送带模式、赤道中央）旧版基线为 2807 台设备，同样在 240003 ms 超时。CPU 采样显示球面装箱占约 61%，多目标寻路占约 25%；下一阶段针对这些真实热点优化，不降低产能、不放宽碰撞规则、不延长生成期限。本阶段未进行游戏内拍建验证。
