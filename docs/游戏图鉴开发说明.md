# 游戏图鉴

## 入口与范围

戴森球工作区 → 图鉴，路由 `/dysonSphere/encyclopedia`。原有首页保持不变。

视觉参考戴森球计划 BWIKI：五列两行分类、切角轮廓、建筑与物品的图标矩阵。颜色、字体与控件沿用本应用日夜主题；窄窗口按内容区重新排列工具栏和图标。

默认展示建筑、物品、科技和资源。十个分类覆盖离线数据与本模块编写的阅读索引；“成就”提供挑战导读，没有接入游戏或 Steam 成就数据库。“工具”连接已有蓝图与资源库页面。

## 数据与资产

当前锁定 FactorioLab 提交 `d3a6e0eeb98a415a85ed544ee66ff7b8cde1810f`，其声明的 DSP 版本为 `0.10.29.21950`；不宣称覆盖最新游戏版本。

转换后包含 64 个建筑条目（含数据源中的工作模式变体）、112 个物品、496 个配方、307 个科技/升级和 22 个采集资源条目。不是对实体数量去重后的“游戏全部建筑数量”。来源、校验和与 MIT 文本放在 `frontend/src/data/encyclopedia/`。

运行时只加载本地静态分片。元数据校验、缓存、搜索与关系解析集中在 `frontend/src/services/encyclopedia/`；页面不调用 Go 业务接口、不读游戏目录、不写数据库。

实体精灵图与参考页同款分类符号作为项目内置素材，位于 `frontend/public/encyclopedia-icons/`，随源码一起提交。目录包含实体精灵图、十个分类 PNG、来源说明和 FactorioLab 仓库许可证文本；原始地址和 SHA-256 固定在 `scripts/encyclopedia/source-lock.json`。图片损坏或缺失时使用打包的 Game Icons 回退。

开发时由 Vite 从 `public/` 提供图片；`npm run build` 会将该目录复制到 `frontend/dist/`，Wails 再将产物嵌入程序。拉取代码后无需额外下载素材，构建和运行不依赖图片源站。

## 维护命令

```sh
# 维护者手动更新固定提交的元数据；客户端运行时不联网。
node scripts/encyclopedia/import-data.mjs

# 维护者需要刷新锁定版本的内置图片时执行；日常开发和构建无需下载。
node scripts/encyclopedia/import-data.mjs --icons

# 检查数据、搜索、关系、单位和坏数据边界。
node scripts/encyclopedia/verify.mjs

cd frontend
npm run build
```

离线维护可使用 `--source-dir <目录>`，目录提供该固定提交的 `data.json`、`zh.json`、`LICENSE`；使用 `--icons` 时还需 `icons.webp` 和 `categories/<分类键>.png`。文件必须匹配锁文件的校验和。

## 搜索与跳转

搜索中文名、英文名、ID、别名与标签；全角/半角与大小写统一。分类、分组和关键词按 AND 生效。列表每页 60 条；总览保留游戏顺序，搜索按匹配权重与中文名称排序。

详情 URL 使用 `kind` 和 `id`，同时携带筛选条件，支持直接访问和刷新。应用外壳以完整 URL 为组件 key，因此 composable 保留会话筛选状态，详情切换不会重置当前列表。非法实体链接提示后回退到列表。

## 动效与验收

- 首次分类入口按顺序短促出现；点击与悬停有轻量反馈；详情沿用 Naive UI 侧边抽屉过渡。
- 支持 `prefers-reduced-motion`，内容不依赖动效完成才能阅读。
- 关键流程：真实导航进入、搜索、空结果、分类/分组、分页、同名类型区分、配方材料与设备跳转、URL 恢复和非法链接回退。
- 页面保留应用外壳，日间样式沿用现有产品规范；检查图鉴区文字、焦点与宽窄窗口布局。
- 复核时发现现有主题动画在 macOS Wails 的 hidden 文档中被跳过，导致主题保存没有执行。已在 `useThemeMode.ts` 补充可见性判断、动画取消降级与 Vue 更新等待；图鉴的首次出场动效在 hidden 状态也直接显示。没有改动主题配色或后端逻辑。
- 已在 macOS Wails 开发模式检查日夜显示、1366×900 / 900×700 / 600×800 布局、主要浏览流程以及日间保存后的重载恢复；日间→夜间→日间连续三轮通过。Windows 实机验证未执行。
