# 副产物与中转缓存

量化按所选配方的实际物料向量联立求解。增产剂消耗、联产、机器内部回收和外部补料进入同一份物料平衡；浮点优化后按原配方的精确分数复核，避免把整数台数因舍入误差多算一台。

## 来源与喷涂

- 来源菜单只列真实配方；“无中生有”伪配方不再对外提供。
- 没有真实生产配方的原料直接作为外部来源；制造品需要外供时使用“改为外部供应”。
- “批量喷涂方案”支持统一加速、额外产出优先和不喷涂。额外产出不可用时采用加速，完全不支持喷涂的配方保持不喷涂。仍可逐配方调整，同配方联产物共用配置。

## 副产物的实际去向

收支面板显示本厂净产出、内部净消耗、外供补足、目标交付和持续过剩。规范流图优先给内部需求分配联产物；同一实际消费口同时接收联产与补料时，蓝图生成真实的输入优先合流门，防止外部供给占满消费带。

剩余物料保留独立出货带或物流设施出货槽。**持续过剩必须由厂外接收或消耗。** 将副产物列为交付目标只改变用途，不能消除物料。出口或所有库存装满后，同配方其他产物仍会被游戏阻塞；生成器不假设无限库存、丢弃或无限发电消耗。

## 中转缓存选项

“生成中转缓存箱/储液罐”默认关闭。开启后：

- 对容量拆分后的机器行净产物建立单物料旁路缓存；固体采用小型储物仓，流体采用储液罐。主通道不经过库存。
- 箱体同侧两根分拣器从连续主带取料并补回；慢速缓存臂只影响缓存速度，不要求承担主带全部吞吐，也不因此自动升档。
- 储液罐采用主输出优先的溢流门和主输入优先的回补门，保留等等级直行主带；主带拥堵时溢流入罐，主带有空隙时补回。罐体使用真实进出带口，两个开关均开启。
- 催化剂等机器内部回流先执行，缓存接在净出口之后，不能截断回收链。
- 普通箱体贴着产物带末端布置；超密度的箱罐旁路独立填入机器间隙，并使用更短的局部接驳；机器回收附件同样允许独立落位，全部供给必须真实接通。
- 超密度箱体和储液罐顶部预留竖向扩建空间，局部布局和寻路共同避让，导出前以最终球面带段独立复核。
- 有限缓存缓解短时停运，不能抵消持续过剩。额外设施与线路会增加占地。

最终检查覆盖来源、绕过库存的主通道、逐带连通、过滤物品、独立箱臂槽位、实际跨度、主带等级、溢流/回补优先参数、罐口几何、库存进出开关及无关来源注入。开启后不具备旁路证明的候选不能成为成功结果。

默认60/min电磁矩阵、一级传送带和一级分拣器曾在开启缓存后封住磁铁出口，现已改为连续主带旁挂箱体。回归另外移除缓存设施及取放支路，独立验证主物流仍然连通，并验证360/min一级主带无需因为缓存臂较慢而升档。

## 验证

截图中的七目标案例使用47台生产设备、3座星际物流塔，超密度赤道环北边缘。独立塔落位后包络面积由2250减至1880，带长由约2160米变为约2178米；保留原设备数和全部连接检查。该结果是具体案例回归，不表示所有方案都达到全局最优。

回归包含默认制造目标及批量喷涂、36组交织副产物设置、真实极小超额需求、普通/超密度四种运输模式、缓存与回流/喷涂/监测器/高纬/升档组合，以及断线、错料、关闭罐口和额外注入反例。

固定种子20261115的随机抽样覆盖24份方案，最终24/24通过；最大案例包含414台生产设备和18519条建筑记录。抽样发现并修复了配送监测器宿主误判、监测器最终转向后的碰撞，以及低轨失败后缺少地面轨备选的问题。随机验收需显式设置环境变量，不计入默认测试：

```powershell
$env:DSBOX_RANDOM_GENERATION='1'
$env:DSBOX_RANDOM_SEED='20261115'
$env:DSBOX_RANDOM_REPORT_DIR=(Join-Path (Get-Location) 'runtime-shots/random-generation')
go test ./helper/blueprint/build/core -run '^TestRandomGenerationSamples$' -v -count=1 -timeout 40m
```

运行：

```powershell
go test ./helper/quant ./helper/blueprint/build/... ./helper/factory/... -count=1
go build ./...
# frontend目录
npm run build
```
