# 超密度缓存布局与生成性能

2026-11-16 整理：本文保留缓存物理约束、数学对照要求和 2026-11-15 历史测量。当前生成入口及候选策略以[唯一 YAML 工作流](../helper/blueprint/build/generator/README.md)为准；历史优化说明及性能数字不构成当前引擎验收证据，本次未运行测试、剖析或游戏验证。

缓存保持旁路语义：主物流不依赖箱臂或库存吞吐。超密度箱体独立填入真实机器间隙，局部主带两端缩短一格；储液罐的双优先门与支路缩短占地。普通布局继续使用原有的固定箱体接驳。

## 顶部扩建空间

对小型储物仓、大型储物仓和储液罐，按原版建造盒横截面在顶面上方保留竖向空间，覆盖生成器最大走线高度。该约束只在超密度布局启用，不把顶部预留变成地面独占空地。

局部轮廓检查、三维寻路索引及最终浮点记录审计都检查真实带段；两端点在仓外、线段穿过仓顶的情况同样拒绝。最终规则报告新增 `storage-roof-clearance`。配送器等库存自身的附加设施不作为传送带处理。

## 历史优化思路与应保持的边界

以下记录历史优化的实现思路及应维持的不变量，不逐项宣称其仍存在于当前引擎或已获得当前测试覆盖。复用、缓存和剪枝都必须与现行唯一 API 对照核实，不能另起一套调度。

- 多终点寻路使用有界分页索引；页按代次隔离，只在本轮首次写入时清空。分数坐标和过大范围保留原后备索引。
- 每个候选的串行寻路复用节点块和堆容量，节点状态每轮完整初始化，返回路线只含坐标值。
- 目标包络之外不查询目标坐标哈希；已知无法改善的邻边不重复检查净空；节点启发值在同一固定目标集内复用。发现新节点或真正松弛时仍执行原硬规则。
- 平移压缩复用各单元空间索引，只重建真正移动的单元。宽相位按共享空间桶判断，考虑端口的四舍五入偏移。
- 动态规则检查在明确的只读阶段复用世界端点，结束即释放快照。第二端点直接映射，避免复制整个建筑记录数组。
- 接驳候选先比较代价，只为获选出口分配路径；没有原生端口许可时不分配空权限表。
- 缓存模式会规范化不能生成实际结构的候选修饰，去重后仍保留独立物流塔等有效能力。
- 原生分拣器先验证全部首选端点，已经无碰撞时直接采用，避免构造无用的备选约束图。存在冲突时按实际OBB冲突拆成独立组件，使用冲突位图及前向检查。互不关联的设备不再参与彼此的回溯，仍保留原回溯预算。
- 原生布局分流曾同时估算制造设备和容量拆行产生的缓存负担，并优先比较均衡矩形。该布局历史不能作为当前候选预算的隐式来源；只交付完整可行候选的要求保留。

正交球面迁移以宿主所在行补偿分流器南北短接头，修正逐点缩放造成的剪切，不放宽槽口射线误差。最终喷涂供剂检查使用与原生单元相同的经向缩放，避免把实际接通的供剂带误判为断线。

不降低原碰撞阈值、传送带或分拣器容量，也不删除最终连接、端口、回流、供电与球面检查。

## 当前显式 YAML 候选策略

2026-11-16 读取磁盘配置：[station.yaml](../helper/blueprint/build/generator/schemes/station.yaml) 的主候选节点显式为 `comparator: layout`、`parallel: 10`、`settleMs: 5000`；可选塔口精修为 `comparator: station-refinement`、`includeCurrent: true`、`parallel: 1`、`reserveMs: 20000`、`timeoutMs: 15000` 和明确超时失败分类。这里的五秒是该节点的显式策略，不是所有模式“首次可行后五秒”的全局保证。

[common.yaml](../helper/blueprint/build/generator/schemes/common.yaml) 按节点配置 `selection: first`、`parallel: 1`、`fallbackOn` 及备选流程；[dense.yaml](../helper/blueprint/build/generator/schemes/dense.yaml) 显式配置密铺参数与地理分支。实际任务使用经校验冻结的配置快照，外部配置及后续修改会改变这些值，不能由本文固定成另一套算法默认。旧“自动两个槽”和旧固定波次/流式双调度不再作为权威。
